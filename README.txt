বাংলা পোশাকের দোকান — সেটআপ নির্দেশিকা
======================================

এই প্যাকেজে যা আছে
- index.html: মোবাইল-ফ্রেন্ডলি দোকান, পণ্য খোঁজা/ক্যাটাগরি, কার্ট, ক্যাশ অন ডেলিভারি অর্ডার ফর্ম
- Code.gs: Google Apps Script কোড, যা অর্ডার Google Sheet-এ জমা করে
- README.txt: এই নির্দেশিকা

গুরুত্বপূর্ণ
------------
এটি একটি প্রাথমিক স্টার্টার ওয়েবসাইট। পণ্যের নাম/দাম/বিবরণ নমুনা; এগুলো আপনার বাস্তব পণ্য নয়।
কোনো হোস্টিং বা Google Sheet নিজে থেকে তৈরি/প্রকাশ করা হয়নি। অর্ডার জমা চালু করতে নিচের সেটআপ সম্পন্ন করুন।
অর্ডার endpoint যুক্ত না করলে সাইট অর্ডার সংরক্ষণ করবে না।

ধাপ ১ — বিনামূল্যে অর্ডার শিট তৈরি
----------------------------------
1. আপনার Google অ্যাকাউন্টে সাইন ইন করুন।
2. https://sheets.google.com খুলে Blank spreadsheet তৈরি করুন।
3. নাম দিন: Fashion Orders.
4. Extensions > Apps Script খুলুন।
5. Code.gs-এর ডিফল্ট কোড মুছে এই প্যাকেজের Code.gs-এর সব কোড পেস্ট করুন।
6. Save করুন।
7. ফাংশন তালিকা থেকে setupSheet নির্বাচন করে Run চাপুন। Google-এর অনুমতি চাইলে নিজের শিটে অ্যাক্সেস অনুমোদন করুন।
8. শিটে Orders ট্যাব ও কলাম-শিরোনাম তৈরি হয়েছে কি না দেখুন।

ধাপ ২ — Apps Script Web App প্রকাশ
----------------------------------
1. Apps Script-এ Deploy > New deployment চাপুন।
2. Select type (গিয়ার/টাইপ নির্বাচন) থেকে Web app বাছুন।
3. Execute as: Me নির্বাচন করুন।
4. Who has access: Anyone নির্বাচন করতে পারলে বেছে নিন। অ্যাকাউন্ট/প্রতিষ্ঠানের নীতি অনুযায়ী এই বিকল্প না থাকলে প্রকাশ সম্ভব নাও হতে পারে।
5. Deploy চাপুন এবং দেখানো Web app URL কপি করুন। এটি সাধারণত https://script.google.com/macros/s/.../exec দিয়ে শেষ হয়।
6. URL-টি গোপন পাসওয়ার্ড নয়, তবে অপ্রয়োজনীয়ভাবে ছড়াবেন না। অর্ডার সংগ্রহ endpoint-এ স্প্যাম ঠেকানোর ব্যবস্থা এই সরল সংস্করণে নেই।

ধাপ ৩ — সাইটে endpoint যুক্ত
----------------------------
1. index.html একটি টেক্সট এডিটরে খুলুন।
2. JavaScript অংশে এই লাইনটি খুঁজুন:
   const ORDER_ENDPOINT = "";
3. উদ্ধৃতির মধ্যে আপনার Web app URL বসান:
   const ORDER_ENDPOINT = "https://script.google.com/macros/s/আপনার-ID/exec";
4. STORE_NAME বদলে নিজের দোকানের নাম দিন।
5. PRODUCTS তালিকায় নিজের পণ্যের নাম, মূল্য, ক্যাটাগরি, বিবরণ বদলান।
6. Save করুন।

ধাপ ৪ — বিনামূল্যে ওয়েবসাইট প্রকাশ (GitHub Pages)
-------------------------------------------------
1. https://github.com এ একটি অ্যাকাউন্ট খুলুন/সাইন ইন করুন।
2. New repository তৈরি করুন। যেমন: bangla-fashion-shop.
3. Public repository বেছে নিন (GitHub Free-তে Pages-এর জন্য এটি প্রয়োজন হতে পারে)।
4. Add file > Upload files থেকে index.html আপলোড করুন; Commit changes চাপুন।
5. Repository > Settings > Pages খুলুন।
6. Build and deployment অংশে Deploy from a branch নির্বাচন করুন; Branch: main, Folder: /(root) বেছে Save করুন।
7. কিছুক্ষণ পরে Pages পৃষ্ঠায় প্রকাশিত URL দেখা যাবে, সাধারণত https://username.github.io/bangla-fashion-shop/।
8. সাইট খুলে মোবাইলেও পরীক্ষা করুন।

টেস্ট করার আগে
--------------
- প্রথমে নিজের নামে একটি ছোট টেস্ট অর্ডার দিন।
- Google Sheet-এর Orders ট্যাবে নতুন সারি এসেছে কি না পরীক্ষা করুন।
- এই সংস্করণে ব্রাউজারের cross-origin সীমাবদ্ধতার কারণে সাইট নিশ্চিত server response পড়তে পারে না। তাই "অনুরোধ পাঠানো হয়েছে" মানেই শিটে সংরক্ষিত নিশ্চিত নয়; শিটে যাচাই করুন।
- পরীক্ষা শেষ হলে টেস্ট অর্ডার মুছুন বা Test হিসেবে চিহ্নিত করুন।

অর্ডার পরিচালনা
---------------
- Google Sheet-এর নতুন সারি হলো নতুন অর্ডার।
- "স্ট্যাটাস" কলামে নতুন / ফোন করা হয়েছে / নিশ্চিত / পাঠানো হয়েছে / সম্পন্ন / বাতিল লিখে অর্ডারের অগ্রগতি রাখুন।
- ক্রেতাকে ফোন করে পণ্যের সাইজ/রং, মোট দাম, ডেলিভারি চার্জ ও ঠিকানা নিশ্চিত করুন।
- পণ্য পাঠানোর পর কুরিয়ার ট্র্যাকিং নম্বর নোট রাখুন।
- সপ্তাহে একবার বাতিল, ফেরত, বিক্রি ও লাভ পর্যালোচনা করুন।
- ক্রেতার ফোন ও ঠিকানা ব্যক্তিগত তথ্য। Google Sheet কখনো Public করবেন না; শুধু বিশ্বস্ত অ্যাকাউন্টে অ্যাক্সেস দিন।

বর্তমান সীমাবদ্ধতা
------------------
- অনলাইন কার্ড/bKash/Nagad পেমেন্ট গেটওয়ে যুক্ত নেই; এই সাইট ক্যাশ অন ডেলিভারি-কেন্দ্রিক।
- লগইন, অ্যাডমিন ড্যাশবোর্ড, স্টক ম্যানেজমেন্ট, কুরিয়ার API ও স্বয়ংক্রিয় SMS নেই।
- Google Apps Script URL যে কেউ ব্যবহার করতে পারে যদি সেটি প্রকাশ্য থাকে; spam/abuse সুরক্ষা ও server-side rate limit যোগ করা দরকার যদি অর্ডার বাড়ে।
- GitHub Pages শুধু static site hosting করে; Google Apps Script অর্ডার সংরক্ষণের জন্য আলাদা backend হিসেবে কাজ করে।
- নিজের পণ্যের ছবি ব্যবহার করতে চাইলে ছবিগুলো repository-তে আপলোড করে HTML-এ ছবির পথ যুক্ত করুন।
